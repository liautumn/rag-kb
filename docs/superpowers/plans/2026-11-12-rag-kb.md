# 本地 RAG 知识库（rag-kb）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `rag-kb` conda 环境中交付一个完全本地运行的 RAG 知识库：CLI 建库 + 浏览器流式问答，LLM 使用 Ollama `qwen3-vl:8b`，嵌入使用 Ollama `bge-m3`，向量库使用 ChromaDB。

**Architecture:** 离线阶段把 `documents/` 中的 PDF/TXT/MD/DOCX 加载、切分并写入 Chroma；在线阶段用 FastAPI 提供检索 + 生成 + SSE 流式接口，前端为无构建步骤的单页聊天界面。思考内容（reasoning 块）在服务端丢弃，永不进入回答或页面。

**Tech Stack:** Python 3.13、LangChain（`langchain-core`/`langchain-ollama`/`langchain-chroma`/`langchain-community`/`langchain-text-splitters`）、ChromaDB、FastAPI、Uvicorn、pytest。

**Spec:** `docs/superpowers/specs/2026-11-12-rag-kb-design.md`

## Global Constraints

- 所有命令在 conda 环境 `rag-kb`（Python 3.13.18）中执行；安装用 `python -m pip`。
- 不调用任何云端 API，不依赖 HuggingFace / torch / sentence-transformers。
- Ollama 地址默认 `http://localhost:11434`；生成模型 `qwen3-vl:8b`；嵌入模型 `bge-m3`。
- `chunk_size=500`、`chunk_overlap=100`、`RETRIEVAL_K=4`、`LLM_NUM_PREDICT=4096`、`LLM_NUM_CTX=8192`。
- 所有面向用户的文案使用简体中文；代码标识符使用英文。
- 思考内容不得出现在回答正文、SSE `delta` 或页面上。
- `ChatOllama` 必须设置 `reasoning=True`：这是让 thinking 内容进入 `additional_kwargs["reasoning_content"]` 而不是混入正文的关键；`reasoning=None` 会把 think 标签留在正文里。
- 每个任务结束时运行该任务的测试并提交一次 git commit。
- 用户可见错误信息必须包含可操作的下一步（例如建库命令、拉取模型命令）。

## Review Focus

以下五类问题最容易让使用者踩坑，计划中每个都分配到具体测试：

1. 思考耗尽输出预算 → 回答为空：`RagService` 必须返回兜底文案（Task 8）。
2. Ollama 未启动 / 模型缺失 → 健康检查为 false，问答返回 503 而不是 500（Task 10）。
3. 知识库为空时提问 → 返回 400 和建库命令（Task 10）。
4. 长中文文本切分 → 每块不超过 `chunk_size`，元数据保留（Task 3）。
5. 同一来源/页码出现多个块 → 先按 (source, page) 去重再编号，保证 `[来源X]` 与来源卡片一致（Task 5、Task 8）。

```python
from langchain_core.documents import Document
from langchain_text_splitters import RecursiveCharacterTextSplitter

CHINESE_SEPARATORS = ["\n\n", "\n", "。", "！", "？", "；", ".", " ", ""]


def build_splitter(chunk_size: int, chunk_overlap: int) -> RecursiveCharacterTextSplitter:
    return RecursiveCharacterTextSplitter(
        chunk_size=chunk_size,
        chunk_overlap=chunk_overlap,
        separators=CHINESE_SEPARATORS,
        length_function=len,
    )


def split_documents(
    documents: list[Document], chunk_size: int, chunk_overlap: int
) -> list[Document]:
    return build_splitter(chunk_size, chunk_overlap).split_documents(documents)
```

- [ ] **Step 3: 实现 `ragkb/loaders.py`**

要点：
- `.pdf` → `PyPDFLoader(str(path)).load()`；`.txt`/`.md` → `TextLoader(str(path), encoding="utf-8", autodetect_encoding=True).load()`；`.docx` → `Docx2txtLoader(str(path)).load()`。
